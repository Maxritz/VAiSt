## 1. Repo Classification

ATOM is a **pure-Python sglang fork** (DeepSeek/AGI Infra). It contains:
- `atom/model_ops/` — attention, moe, linear, sampler, layernorm, rotary, activations (Python wrappers dispatching to Triton kernels)
- `atom/model_engine/` — scheduling, kv-cache, block manager, engine core (Python orchestration)
- `atom/kv_transfer/` — KV cache transfer/offload/disaggregation (Triton kernels in `triton_kv_staging.py`)
- `atom/quantization/` — weight quantization (Python, ggml-compatible)
- `atom/plugin/sglang/`, `atom/plugin/vllm/` — backend plugins wrapping sglang/vllm APIs
- **Zero `.cu`/`.cpp` kernel sources** — all compute is Triton-Python (`triton` package) or pytorch ops.

The target explicitly **eliminates Python/Triton**. So ATOM's compute layer maps entirely to VAiSt's C++/Vulkan stack.

## 3. Risk Cascade & Dependency Waterfall

```
ATOM compute layer (Python+TRITON)
  ├─ attention_dispatch → needs paged-attention Vulkan shader (MISSING, create)
  ├─ linear/matmul → mul_mat_q entry point → qgemm shaders (4 new + 7 existing ✓)
  ├─ moe → moe_route.comp (new ✓) + qgemm dispatch (existing ✓)
  ├─ layernorm → vkmath/layernorm (existing ✓)
  ├─ rotary → inline in attn shader (needs new shader or fusion)
  ├─ sampler → C++ host (stdlib) or GPU sort (may need new shader)
  └─ kv_transfer → Vulkan buffer ops (needs vaist_tp/vklinalg integration)

Critical path: attention_dispatch (no Vulkan attn shader exists yet)
```

## 4. Debug-Hypotheses

| Target layer        | Risk                                | Hypothesis test                                    |
|---------------------|-------------------------------------|----------------------------------------------------|
| MLA attention       | Rope fp16 precision loss            | Validate Q/K cos/sin values vs Python ref (probe: `vaist_attn_mla.comp` intermediate) |
| MoE routing         | Gate-score overflow in fp16         | Check dot product magnitude with large k_gate (probe: `moe_route.comp` best_score) |
| qgemm q2_K          | 2-bit pack offset error             | Verify `level = (qbyte >> (j*2)) & 3` matches ggml (probe: byte-exact vs llama.cpp) |
| paged-KV            | Page table stride mismatch          | Compare physical address mapping vs ATOM's `paged_attention.py` block mapping |
