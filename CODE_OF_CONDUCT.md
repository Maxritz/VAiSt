# Code of Conduct

VAiSt is licensed under Apache 2.0, which means legally, you can use it for almost anything. This document is the "almost".

We don't want this project, or anything built on top of it, used to develop, promote, or carry out hatred, harassment, or violence against any person or group, whether that's on the basis of race, religion, caste, gender, sexuality, nationality, disability, or anything similar. That includes systems built specifically to target or discriminate against a group with the intent to cause them harm.

This is a community standard, not a license restriction. The Apache 2.0 grant itself stays unrestricted, that's deliberate, since a legally untested usage-restriction clause tends to make lawyers nervous and companies avoid the project altogether. This document says plainly what we expect from anyone participating in or building on this project, even where the license doesn't require it.

Beyond that one line: be reasonably civil in issues and pull requests, don't be the reason a maintainer has to write a longer document than this one, and use good judgement.

If you run into behaviour in this project's spaces that crosses the line above, open an issue or contact a maintainer directly.
